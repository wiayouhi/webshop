# 🛒 PHP E-Commerce Store (Educational Project)

ระบบร้านค้าออนไลน์พัฒนาด้วย PHP และ MySQL สำหรับใช้ **ศึกษาและเรียนรู้** พื้นฐานการเขียนโปรแกรมเท่านั้น

---

## 👨‍💻 Developed by / พัฒนาโดย
* **Author:** [Thanawat.wia]
---

## ✨ Features / คุณสมบัติ
* **Shop:** แสดงสินค้าและหมวดหมู่ (Product Listing)
* **Cart:** ระบบตะกร้าสินค้า (Shopping Cart)
* **Auth:** ระบบสมาชิกและจัดการ Session (Login/Register)
* **Admin:** ระบบจัดการข้อมูลหลังบ้าน (Basic CRUD)
